# 供應鏈新聞觀測站

半導體供應鏈新聞觀測站：依料件群組（處理器、網卡模組、記憶體 & 固態硬碟、封測、晶圓）分類瀏覽新聞，並顯示匯率、台美經濟指標、市場情緒指標（VIX、貪婪與恐懼指數）。新聞與各項數字串接真實公開資料來源，來源暫時無法取得時會自動改顯示示範資料，並清楚標示「示範資料」。

## 如何啟動網站

網站需要先啟動一個小伺服器（同時負責顯示網頁、抓取即時資料），**不能再用雙擊 `index.html` 的方式打開**。

在 PowerShell 中：

```powershell
cd "D:\新聞網站\server"
node server.js
```

看到「供應鏈新聞觀測站伺服器已啟動：http://localhost:8000」之後，打開瀏覽器輸入：

```
http://localhost:8000
```

伺服器只要一直開著（PowerShell 視窗不要關），網站就能正常使用。要關閉時，在 PowerShell 視窗按 `Ctrl+C`。

### 第一次使用需要先安裝套件

如果是第一次在這台電腦上啟動，要先安裝一次相依套件（之後不用再裝）：

```powershell
cd "D:\新聞網站\server"
npm install
```

## 真實資料來源

| 資料 | 來源 | 是否需要金鑰 |
| --- | --- | --- |
| 新聞 | Google 新聞 RSS | 不需要 |
| 匯率（美元/台幣、日圓/台幣、美元/日圓） | ExchangeRate-API | 不需要 |
| 台灣 CPI／PPI／GDP 成長率 | 政府公開資料 | 不需要 |
| 台灣央行重貼現率 | 中央銀行開放資料（該系統本身不穩定，偶爾會顯示示範資料） | 不需要 |
| VIX 恐慌指數、CNN 貪婪與恐懼指數 | Yahoo Finance／CNN | 不需要 |
| 美國 CPI／PPI／GDP／聯邦基金有效利率 | FRED（美國聯準會） | 需要，已設定在 `server/.env` |

## 網站結構

| 頁面 | 檔案 | 內容 |
| --- | --- | --- |
| 首頁 | `index.html` | 5 個料件群組精選新聞、右上角市場快照（匯率、台美經濟指標、市場情緒指標） |
| 處理器 | `processor.html` | 處理器相關新聞，可依類型篩選 |
| 網卡模組 | `network.html` | 網卡模組相關新聞，可依類型篩選 |
| 記憶體 & 固態硬碟 | `memory.html` | 記憶體與固態硬碟相關新聞，可依類型篩選 |
| 封測 | `packaging.html` | 封測相關新聞，可依類型篩選 |
| 晶圓 | `wafer.html` | 晶圓代工相關新聞，可依類型篩選 |

## 檔案結構

```
D:\新聞網站\
├── index.html / processor.html / ...   前端頁面
├── css/style.css                        樣式
├── js/
│   ├── data.js        示範資料（各項來源暫時失敗時的備援內容）
│   ├── api.js          向後端抓即時資料，失敗時自動改用 data.js 的示範資料
│   ├── layout.js / components.js / main.js   版面與渲染邏輯
└── server/
    ├── server.js        伺服器進入點（顯示網頁 + 提供 /api/* 資料）
    ├── routes/          rates.js（匯率）、indicators.js（經濟指標）、sentiment.js（VIX/貪婪指數）、news.js（新聞）
    └── .env             你自己的 FRED 金鑰放這裡（不要外流分享這個檔案）
```

## 如何更新示範資料（備援內容）

示範資料集中在 `js/data.js`，只有在對應的真實資料來源暫時失敗時才會顯示。要調整示範內容，編輯這份檔案即可，不需要改 HTML。
